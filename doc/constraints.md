# 39 个样例给 $F[t]$ 的双侧约束

## 口径

矿物量恒为偶数（初始 50，采矿 +8，各项成本 100/400/50），故全程**折半**存储以免 $m<2^{64}$ 溢出。

- $F[t]$ = 时刻 $t$（即 $10t$ 秒）可达的最大**折半**矿物量
- 答案 $= 10\cdot\min\{t : 2F[t]\ge m\}$

## 每个样例给出两条约束

样例 $(m,\ 10t)$ 同时蕴含：

$$2F[t]\ \ge\ m \qquad\text{且}\qquad 2F[t-1]\ <\ m$$

前者是**下界**（要达到的），后者是**上界**（不得顶破的禁区）。任何改进都必须同时满足两侧。

## 关键结论：不能整体抬高曲线

把全部约束折算到同一归一化尺度 $2F[t]/\rho^{\ast t}$（$\rho^\ast=1.053027864$）：

```
F[331] <  上界  ->  360.209813        F[496] <  上界  ->  360.209824
F[333] >= 下界  ->  360.209812        F[500] >= 下界  ->  360.209825
                                      F[502] <  上界  ->  360.209825
```

$t\approx500$ 处的可行窗口是**负的**（$-1.4\times10^{-9}$）：若曲线严格水平，则不可能同时满足 $t=496$ 的上界与 $t=500$ 的下界。这说明真实最优曲线在这一段**不是水平的**，而带有 $\sim10^{-9}$ 量级的微小上翘（应来自基地 2 步生产周期与 12 步建造流水线的相位效应）。

实践含义：

- **均匀抬高 $2.2\times10^{-7}$ 会修好 $t=500$ 但同时顶破 $t=496$**，净收益为零甚至为负。
- 改进必须**逐点**：只把特定 $t$ 的值提上去。
- 这样做完全合法——表中每项都是独立的可达下界，且可达值恒 $\le$ 真值，故逐点提升只会让答案单调趋近正确，不会把原本正确的样例改错（前提是新值确实由一条**已验证可行**的动作序列产生）。

因此 `src/check.py` 每次都会打印禁区余量；任何一项变成非正即判定该表不可用。
