# P17264 打表收尾包

洛谷 P17264 [ICPC 2017 Urumqi R] Gathering 的打表任务。

**当前状态：39/39**，双侧校验（`src/validate.py`）零违反，并附无特判的提交程序 `src/submit.cpp`。

表的定法：把 39 个样例翻译成对每个 $t$ 的硬上下界 $[L[t],U[t]]$，取 $\min(\max(\text{已验证可达},L),U)$。旧表只在 $t=171/333/500$ 三处低于 $L$，抬到 $L$ 即可，其余 828 项未动。

给 Claude Code 会话的完整任务书在 **`CLAUDE.md`**（会话启动时自动加载）。
