# P17264 打表收尾包

洛谷 P17264 [ICPC 2017 Urumqi R] Gathering 的打表任务。

**当前状态：39/39**（见 `doc/findings.md`）。三个目标点都由从 $t=0$ 出发、经独立模拟器逐步验证过的完整动作序列支撑，四个禁区余量未动。

给 Claude Code 会话的完整任务书在 **`CLAUDE.md`**（会话启动时自动加载）。

## 快速开始

```bash
bash run.sh selftest     # 阶段 0：工具链自校验，必须先过
bash run.sh check        # 看当前表的 39 样例结果与禁区余量
bash run.sh build        # 只编译，不跑
bash run.sh cert         # 独立复核可达性证书
```
